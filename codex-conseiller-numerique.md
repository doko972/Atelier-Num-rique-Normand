# CODEX — Site web de Conseiller Numérique

## 1. Présentation du projet

Créer un site web professionnel, accessible et rassurant destiné à présenter une activité de **Conseiller Numérique** auprès des habitants d’une commune et des communes voisines.

Le service s’adresse principalement :

- aux personnes retraitées ;
- aux personnes peu à l’aise avec l’informatique ;
- aux habitants ne disposant pas d’un accompagnement numérique de proximité ;
- aux personnes rencontrant des difficultés avec les démarches administratives en ligne ;
- aux associations, petites structures locales et aidants familiaux.

Le rôle du Conseiller Numérique est d’accompagner, guider et former les habitants dans l’utilisation des outils informatiques, d’Internet, des smartphones et des services administratifs en ligne.

Le site ne doit pas donner l’impression d’une entreprise informatique froide ou complexe. Il doit inspirer immédiatement :

- la confiance ;
- la proximité ;
- la patience ;
- la pédagogie ;
- la simplicité ;
- la confidentialité ;
- l’accompagnement humain.

---

## 2. Objectifs du site

Le site doit permettre de :

1. présenter clairement le rôle du Conseiller Numérique ;
2. expliquer les services proposés ;
3. rassurer les personnes âgées ou peu expérimentées ;
4. permettre une demande de rendez-vous simple ;
5. publier les dates d’ateliers collectifs ;
6. informer sur les tarifs, lieux et modalités d’intervention ;
7. permettre aux communes, associations et CCAS de demander un partenariat ;
8. publier des conseils pratiques et des fiches d’aide ;
9. administrer facilement le contenu du site ;
10. respecter les règles françaises en matière d’accessibilité, de confidentialité et de protection des données.

---

## 3. Positionnement du service

Le service doit être présenté comme un accompagnement humain et pédagogique.

Le Conseiller Numérique ne fait pas les démarches à la place de l’usager lorsque celles-ci nécessitent une décision personnelle, une déclaration sur l’honneur ou la transmission d’informations sensibles.

Il accompagne la personne pour qu’elle comprenne ce qu’elle fait et gagne progressivement en autonomie.

### Message principal

> Le numérique ne doit laisser personne de côté.  
> Je vous accompagne pas à pas, à votre rythme, près de chez vous.

### Promesse

- explications simples ;
- accompagnement sans jugement ;
- exercices pratiques ;
- rythme adapté ;
- possibilité de venir avec son propre appareil ;
- confidentialité des échanges ;
- soutien ponctuel ou suivi dans la durée.

## 5. Identité visuelle

Créer une interface moderne, chaleureuse et très lisible.

### Style général

- design sobre ;
- ambiance locale et humaine ;
- grands espaces ;
- boutons visibles ;
- textes courts ;
- pictogrammes explicites ;
- peu d’animations ;
- aucune surcharge visuelle ;
- navigation évidente ;
- contraste élevé ;
- langage simple.

### Palette recommandée

Utiliser une palette douce et rassurante :

- bleu principal : confiance et service public ;
- vert secondaire : accompagnement et progression ;
- beige ou blanc cassé : chaleur et lisibilité ;
- gris foncé pour les textes ;
- orange doux uniquement pour les appels à l’action.

Exemple :

- `#255C75` — bleu principal ;
- `#3F7D6B` — vert secondaire ;
- `#F7F3EA` — fond clair ;
- `#252525` — texte ;
- `#D9772E` — appel à l’action ;
- `#FFFFFF` — surfaces.

La palette pourra être adaptée à l’identité visuelle de Luminis Digital ou de la future marque choisie pour le service.

### Typographie

Utiliser une police sans-serif très lisible.

Polices possibles :

- Atkinson Hyperlegible ;
- Lexend ;
- Inter ;
- Source Sans 3.

Taille minimale recommandée :

- texte courant : 18 px sur ordinateur ;
- texte courant : 17 px sur mobile ;
- interligne : minimum 1,5 ;
- boutons : minimum 18 px.

## 6. Principes d’accessibilité

Le site doit viser une conformité élevée avec le **RGAA** et les recommandations **WCAG 2.2 niveau AA**.

Prévoir obligatoirement :

- navigation complète au clavier ;
- focus visible ;
- contrastes suffisants ;
- textes alternatifs pour les images ;
- titres structurés ;
- formulaires avec labels explicites ;
- messages d’erreur compréhensibles ;
- liens descriptifs ;
- absence de textes trop petits ;
- zoom navigateur sans perte de contenu ;
- boutons suffisamment grands ;
- aucune information transmise uniquement par une couleur ;
- mode contraste renforcé ;
- option d’augmentation de la taille du texte ;
- bouton permettant de réduire ou désactiver les animations ;
- lecture correcte avec un lecteur d’écran ;
- menu simple et peu profond ;
- fil d’Ariane sur les pages internes ;
- possibilité d’imprimer les fiches pratiques ;
- version PDF accessible des guides importants.

Ne pas utiliser :

- de carrousel automatique ;
- de texte animé ;
- de vidéo en lecture automatique ;
- de pop-up intrusive ;
- de captcha complexe ;
- de menu caché difficile à comprendre ;
- de jargon technique non expliqué.
